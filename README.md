# GoT Tracker — Board Game Companion

A static, responsive fan-made companion for *A Game of Thrones: The Board Game* and the *Mother of Dragons* expansion.

## Features
- Side-by-side base game and Mother of Dragons rulebook cards
- One embedded YouTube tutorial titled **video tutorial**, with YouTube's built-in full-screen control and an external YouTube link
- Two scoreboards: up to 6 players for the base game and up to 8 for the expansion
- Date and game-duration fields, live placement-based rankings, average game duration, leader/tie display, local browser storage, CSV export
- Responsive dark fantasy-inspired design

## Run locally
Open `index.html` in a modern browser. No build tools or server required.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository named `gottracker`.
3. Upload `index.html` and this `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Your site should be available at `https://YOUR-USERNAME.github.io/gottracker/`.

## Important notes
- Scores are stored in the current browser only; they are not shared across users/devices.
- Rulebooks are linked from their source websites rather than copied.
- The site is fan-made and is not affiliated with the game's publisher, HBO, or George R. R. Martin.
